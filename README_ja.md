# LLM のモデル学習における無闇矢鱈に学習しないことの重要性 -- 幾何学的な線形及びログスケールクランプによるゼロ活性化スパースTransformerの実現
# (英語副題: The Importance of Selective Non-Learning: Realizing Zero-Activation Sparse Transformers via Log-Linear Geometrical Clamping)

半導体不足が辛いので、この理論がLLMの計算効率化のきっかけになることを祈る。

## 概要
現代の大規模言語モデル（LLM）開発における「すべてのデータの関連性を問答無用で学習させる」という方法は、無駄なノイズを学習してしまうことで、却って学習能力を下げているという疑いがある。
本論文では、知能の効率的な成長には「関係のないノイズを徹底的に無視し、無闇矢鱈に学習させないことこそが肝要である」という仮説を提唱する。
その幾何学的な実証構造として「LogLinearActiveHead (LoLi-MLP)」を、短時間で学習可能なモデルの１つとして提案する。

LiLi-MLP は、「１つの文脈野中には、整数スケールとログスケールのパターンが埋め込まている」という仮説に基づいた学習モデルある。
意味ベクトルの幾何学的な関連性を、「整数スケールとログスケールのみで表現するものと決め打ち」し、「それ以外の外れ値は無効なデータとして学習しない」ことで実現している。

実装は "Qwen/Qwen2.5-0.5B" の head 層のみを差し替える形で行った。
つまり、tokenizer, attention はそのまま Qwen2.5 のものを利用し、context の関連性のみを Wikipedia の日本語データで学習させた。

モデルの学習には、NVidia RX5070 を１個だけ用いた。Wikipedia の日本語データを学習し、5時間ほどで Loss 2.0982 まで到達した。
その後、日本語返答の仕上げとして、日本語の会話データを5分ほ学習して微調整を行ったところ、ずれた回答ではあるが学習量・時間に対しては十分な応答を返すようになった。

## LogLinearActiveHead (LoLi-MLP)

このモデルの仕組みは、「input -> attention -> 回転(直交化) -> head -> output」というLLMの処理の流れにおいて、

1. head に入力する意味ベクトル x 入力する変わりに 「"x", "log x" を直結したベクトル」を入力として用いる
2. 外れ値を学習しないために、準談判時に「0以下の値は0」「1以上の値は1」、逆伝搬の際に勾配0として学習が発生しないようにする

という２点の仕組みによって実現している。

## この理論は何の役に立つか？

1. モデルの学習時間の高速化
    a. データ量が多いほど、学習が高速化する
    b. データ量が多いほど、Loss の下限値が深くなる
2. 演算処理の0  スパース化
    a. 0 演算処理を高速化する GPU 機能を用いることで、電力消費が可能
    b. また、0 演算が入ることで処理を高速化することも可能

この２点だけでも、商用の LLM を作成・運用する企業であれば、かなりに経費削減につながる効果だと考えている。

## 課題

1. Loss 以外のモデルの学習状況の評価指標の必要性
    a. 10分程度の学習では、日本語の文法構造は学習できても、細かい単語候補の予測精度までは学習できない
    b. にもかかわらず、Loss の値は 5.0 以下になることも多い
2. モデル自体のゼロスパース化
    a. 元々は個人PCで使うための、0スパースなLLMを作るために考えた理論だった
3. LoRA アダプタ
    a. 軽量な学習モデルなので LoRA アダプタとして、ローカルのPCでも使いやすいと思われる
